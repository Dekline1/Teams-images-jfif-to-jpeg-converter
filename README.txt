Convert JFIF (.jfif) file to JPEG (.JPEG).

REQUIRED python 3.##

Place the files you want to convert in the "Input" folder. The script will convert each image with the same name as the original without deleting the original, move the new files to the "Output" folder, and then exit automatically.

//


Konwersja pliku JFIF (.jfif) na JPEG (.JPEG).

WYMAGANY python 3.##

Umieść pliki które chcesz zamienić, w folderze "Input". Skrypt przekonwertuje każdy napotkany obraz nadając mu taką sama nazwę jak oryginał, bez usuwania tego oryginału, przeniesie nowe pliki do folderu "Output", a następnie samoczynnie się wyłączy.
